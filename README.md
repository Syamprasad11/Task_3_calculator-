# Web Development Internship – Task 3

This repository contains **Task 3** of my Web Development Internship. The task focuses on creating a functional calculator using HTML, CSS, and JavaScript.

## Project Overview

The project is a simple and interactive **web-based calculator** that allows users to perform basic arithmetic operations through a user-friendly interface.

## Contents

- **index.html** – Contains the structure and layout of the calculator.
- **style.css** – Provides the styling and visual design of the calculator.
- **script.js** – Contains the JavaScript logic used to perform calculations and handle user interactions.

## Features

- Simple and user-friendly calculator interface
- Basic arithmetic operations
- Interactive buttons
- Real-time calculation
- Clean and organized design

## Technologies Used

- HTML
- CSS
- JavaScript

## Purpose

This project was created as part of my Web Development Internship to practice HTML structure, CSS styling, and JavaScript programming and to build an interactive web application.

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Use the calculator to perform arithmetic operations.
